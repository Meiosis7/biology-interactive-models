# 膜电位分步解释设计

## 目标

在同一页面中把动作电位拆成七个可点击步骤：静息状态、达到阈值、去极化、峰值/反极化、复极化、超极化、恢复静息。每一步与曲线位置、膜电位、通道开闭和离子运动同步。

## 过程划分

1. 静息状态：约 −70 mV，电压门控 Na⁺、K⁺ 通道关闭。
2. 达到阈值：由 −70 mV 升至约 −55 mV，达到阈值后触发 Na⁺ 通道大量开放。
3. 去极化：Na⁺ 大量内流，膜内电位快速升至正值。
4. 峰值/反极化：约 +30 mV，Na⁺ 通道失活，K⁺ 通道开始成为主要开放通道。
5. 复极化：K⁺ 外流，膜内电位由正值下降并恢复为负值。
6. 超极化：K⁺ 通道关闭较慢，K⁺ 继续外流，膜电位短暂低于静息电位至约 −80 mV。
7. 恢复静息：K⁺ 通道逐渐关闭，漏通道和钠钾泵维持离子梯度，膜电位回到约 −70 mV。

## 交互与布局

- 在主画布和实验控制台之间增加分步解释区，桌面端不离开当前视角。
- 顶部七个步骤按钮显示序号和阶段名称；当前步骤高亮。
- 点击步骤后暂停播放并跳转至该阶段代表时间点。
- 解释区显示当前步骤的核心变化、通道与离子、进入下一阶段的原因。
- 选择弱刺激时仍显示“阈下局部电位”的专用解释；点击七步导航会切换到阈刺激以展示完整动作电位。
- 窄屏步骤条可横向滚动，解释内容纵向排列。

## 验收标准

1. 七个阶段按钮均可点击并跳到正确阶段。
2. 超极化和恢复静息是两个独立阶段，曲线分别表现为低于 −70 mV和回到 −70 mV。
3. 每一步至少说明电位、通道/离子和阶段结果。
4. 点击阶段后曲线指针、阶段标题、离子通道和解释同步。
5. 现有连续离子动画、刺激强度、播放、速度、对比曲线和重置功能保持可用。
