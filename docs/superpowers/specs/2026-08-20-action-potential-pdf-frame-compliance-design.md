# 动作电位模型 PDF 逐帧修订设计

日期：2026-08-20

## 目标

以用户提供的《动作电位的形成和传导 修改.pdf》为本轮唯一视觉与文案修订依据，使“动作电位产生”和“动作电位传导”的每个阶段都与批注要求一致。本轮重点修正刺激标记的生命周期和逐阶段说明，不改变已经确认的膜结构、离子分布、离子轻微自由移动、通道与离子路径、局部电流方向或手动“下一步”交互。

## 设计原则

1. 页面只展示当前阶段需要的信息，不把上一阶段的提示遗留到下一阶段。
2. “刺激”文字和红色指示线属于一次性的起始提示，不是持续存在的结构。
3. 全部位置描述统一使用“受刺激部位”或“相邻部位”，不再使用“中央”“中央膜段”等容易误导的说法。
4. 不增加“第一步”“第一轮”等编号，也不重复显示底部传导说明。
5. 产生模式继续循环播放；传导模式继续由用户点击“下一步”逐阶段推进。

## 刺激标记状态合同

刺激标记包含“刺激”文字和红色指示线，两者作为同一元素整体出现或消失。

- 产生模式：仅在 `stimulus` 阶段显示。
- 产生模式的 Na⁺ 通道开放、Na⁺ 内流和受刺激部位兴奋阶段：不显示。
- 传导模式：从初始画面到最终结果，所有阶段都不显示。
- 静息模式：不显示。
- 暂停只冻结当前画面，不得让已消失的刺激标记重新出现。
- 重新播放产生模式时，回到起始刺激阶段后再次显示。
- 切换模式后，显示状态必须由新模式和新阶段重新计算，不能沿用旧画面。

实现采用显式的逐帧状态判断：只有 `mode === "generation" && phase === "stimulus"` 时渲染刺激标记。不会通过仅降低透明度的方式隐藏，以免不可见元素继续占据无障碍树或遮挡点击。

## 逐阶段文案

### 动作电位产生

依次显示：

1. “刺激局部神经纤维”
2. “受刺激部位 Na⁺通道开放”
3. “Na⁺从上下通道进入受刺激部位膜内”
4. “受刺激部位兴奋，膜外为负、膜内为正”

其中仅第 1 项同时显示刺激文字和红色指示线；第 2 项开始立即移除。

### 动作电位传导

依次显示：

1. “受刺激部位已经形成动作电位”
2. “形成局部电流”
3. “局部电流使相邻部位 Na⁺通道开放”
4. “Na⁺从上下通道进入相邻部位膜内”
5. “相邻部位形成动作电位”

后续轮次仍按“形成局部电流 → 相邻部位通道开放 → Na⁺进入 → 相邻部位形成动作电位”的内容推进，但界面不显示轮次或步骤编号。

终态结果固定为：

“神经冲动以电信号（局部电流）的形式在神经纤维上双向传导。”

## 禁止出现的内容

- 产生模式第一阶段以外的“刺激”文字或红色指示线。
- 传导模式中的任何刺激标记。
- “中央”“中央膜段”。
- “第一步”“第几步”“第一轮”“第二轮”“第三轮”等编号描述。
- “兴奋由中央向两侧逐段传导”等已经要求删除的底部重复说明。
- 已删除的页面副标题和“离子、通道和传导方向均为教学示意”等备注。

## 实现范围

预计只调整动作电位模块中的以下职责：

- 场景组件：根据模式和阶段决定是否渲染刺激标记。
- 帧说明数据：核对并统一上述逐阶段文案。
- 组件与实验室测试：增加刺激标记生命周期、切换模式、暂停和重播回归覆盖。

本轮不修改：

- 膜内 K⁺ 多、Na⁺ 少，膜外 Na⁺ 多、K⁺ 少的分布。
- 游离离子的轻微自由移动及减弱动态模式。
- 正负号、上下膜蛋白、通道左右开启方式。
- Na⁺ 经通道进出的路径。
- 局部电流短弧线的方向与逐渐绘制动画。
- 传导模式“下一步”控制、阶段顺序和最终双向传导结论。
- 移动端紧凑布局。

## 验收标准

### 自动化验收

- 产生模式首帧存在且仅存在一个刺激标记。
- 产生模式进入通道开放、Na⁺ 内流和兴奋帧后，DOM 与无障碍树中均不存在刺激标记。
- 传导模式所有帧均不存在刺激标记。
- 暂停不会改变当前刺激标记状态。
- 产生模式重新播放会回到刺激标记可见的首帧。
- 模式切换不会残留上一模式的刺激标记。
- 所有阶段文案与本设计逐字一致。
- 页面不存在本设计列出的禁用文案。
- 现有离子、通道、局部电流、循环播放、手动推进和减弱动态测试继续通过。

### 浏览器验收

在 1280×720 和 390×844 两种视口逐阶段检查：

- 刺激标记只在产生模式第一阶段出现。
- 标记消失后不残留空白占位、遮挡或点击区域。
- 暂停、继续、重新播放和切换模式行为正确。
- 文案没有溢出、重叠或被截断。
- 手机端“下一步”仍在首屏可操作区域内。
- 浏览器控制台无新增错误或警告。
