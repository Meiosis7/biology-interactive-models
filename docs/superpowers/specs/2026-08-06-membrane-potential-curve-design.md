# 膜电位变化曲线：动态交互模型设计

## 1. 学习目标

学生完成模型后应能：

1. 读出静息电位、阈电位、峰值和恢复阶段。
2. 根据曲线斜率和方向判断膜电位变化。
3. 将 Na⁺通道、K⁺通道和相应离子流与曲线阶段对应。
4. 区分阈下局部电位和完整动作电位。
5. 理解阈上不同刺激强度不改变单个动作电位峰值。
6. 在“辨析模式”中根据给定位置判断阶段、离子流和膜内外电性。

## 2. 页面结构

左侧为可交互膜电位曲线，右上为膜局部剖面和离子通道，右下为阶段解释与答题区。曲线游标可拖动；膜剖面、离子流、膜内外电性和解释卡随游标同步。

## 3. 模式

- 探究模式：选择弱刺激、阈刺激或强刺激，自由拖动游标。
- 辨析模式：系统给出随机曲线位置，学生选择阶段、主要离子运动和膜内外相对电性，立即反馈。
- 对比模式：在同一坐标系叠加阈刺激与强刺激，突出“全或无”；也可叠加弱刺激局部电位。

## 4. 曲线与阶段

- 静息电位约 −70 mV。
- 阈电位参考线约 −55 mV。
- 去极化：Na⁺通道开放增加，Na⁺内流，膜内电位升高。
- 反极化：峰值约 +30 mV，膜内相对为正。
- 复极化：K⁺通道开放增加，K⁺外流，膜电位下降。
- 恢复：短暂低于静息水平后返回约 −70 mV。
- 阈下刺激：只出现幅度有限的局部电位，不出现完整动作电位。

## 5. 交互

- 刺激强度三档。
- 游标拖动与键盘调整。
- 显示/隐藏阶段标签、阈电位线和离子提示。
- 播放、暂停、单步、慢速/正常、重置。
- 辨析模式提供累计正确数和当前题解释，但不进行排名或持久化。

## 6. 防误解设计

- 曲线时间轴使用“教学时间单位”，避免暗示真实秒尺度。
- 曲线为典型示意，不表示所有神经元精确相同。
- 强刺激不提高单个动作电位峰值。
- 将“动作电位幅度”和“多个动作电位频率”明确区分；首版不模拟频率编码。

## 7. 验收标准

- 游标、通道状态、离子流和解释同步。
- 阈刺激与强刺激完整动作电位峰值相同。
- 弱刺激只显示局部电位。
- 辨析题覆盖全部阶段并能给出针对性解释。
- 所有图例除颜色外均包含文字或形状标记。
