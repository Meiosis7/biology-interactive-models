# 膜电位曲线渐进形成设计

## 目标

膜电位曲线不再进入页面就完整显示，而是随实验时间从左向右逐渐形成。学习者在同一视角中同时观察曲线、通道状态、离子运动和当前阶段原因。

## 方案比较

1. **按当前时间生成曲线点（采用）**：只计算并绘制 0 到当前时间的曲线，语义直接，播放、拖动和重置都自然同步。
2. 用遮罩盖住未来曲线：视觉上可行，但画布仍先绘制完整答案，交互与测试不够清晰。
3. 累积历史点缓存：适合不可逆实时采样，但拖动回退需要额外维护缓存，不适合本模型。

## 交互设计

- 初始 0 时刻只保留曲线起点，不显示未来走势。
- 点击“开始”后，曲线端点随时间向右移动并形成已发生的轨迹。
- 拖动曲线或时间轴时，只显示目标时刻之前的轨迹；向左拖动会收回尚未发生的部分。
- 点击阶段步骤时，曲线直接形成到该阶段对应时刻，同时离子运动、通道状态和阶段原因同步切换。
- 开启“对比曲线”后，所有对比曲线也只形成到当前时刻。
- 重置后回到只有起点的状态。

## 实现边界

- 在 `CurveCanvas.tsx` 中提供可测试的 `getVisibleCurveTimes(time)`，返回从 0 到当前时刻的采样时间。
- 现有曲线形状、阶段划分、控制方式、膜结构动画和文字讲解不变。
- 不增加新的页面、弹窗或额外操作步骤。

## 验收标准

- `time = 0` 时只有一个曲线采样点。
- `0 < time < 6` 时最后一个采样点等于当前时间，且没有未来采样点。
- `time = 6` 时完整曲线包含 241 个采样点。
- 播放、拖动、阶段跳转、对比和重置继续由同一时间状态驱动。
