# 膜电位模型 AI 素材融合设计

## 目标

复用此前突触模型中的 AI 生成透明素材，让离子粒子和通道蛋白具有真实的生物结构质感，同时保持膜电位模型的教学清晰度和现有交互逻辑。

## 素材审查

- `receptors-layer.png`：透明背景，包含多个膜受体和通道蛋白，适合以精灵图裁切方式复用。
- `transmitters-layer.png`：透明背景，包含多个发光小球和分子团，适合选取简单球形区域作为离子表面纹理。
- `synapse-cross-section.png`：包含完整突触场景，不适合作为膜电位模型主体，避免复用。
- `vesicles-layer.png`：包含囊泡结构，与本模型知识内容无关，避免复用。

## 方案

采用“AI 素材质感 + 清晰教学标注”的混合视觉：

- Na⁺ 与 K⁺ 通道继续保留明确的文字、开关状态和位置，但通道主体改为从 `receptors-layer.png` 中选取的两种蛋白外形。
- 关闭通道降低饱和度和对比度；开放通道恢复彩色、轻微放大并显示对应颜色的外发光。
- 膜两侧的 Na⁺ 与 K⁺ 粒子使用 `transmitters-layer.png` 中的圆形小球作为纹理，Na⁺ 调整为蓝绿色，K⁺ 保持琥珀色；文字标记继续叠加在粒子上。
- 流动路径上的三个运动点使用同一 AI 小球纹理，沿已经验证的通道路径运动。
- 细胞膜、膜内外标签、大方向箭头和曲线不改为写实图，以保持示意关系清楚。

## 实现约束

- 原图通过 CSS `background-image` 与 `background-position` 复用，不生成新的位图裁切文件。
- 主项目直接引用 `/synapse-cinematic/receptors-layer.png` 与 `/synapse-cinematic/transmitters-layer.png`。
- 独立成品只复制这两个必要素材，不复制整套突触素材。
- 图片仅承担视觉质感，Na⁺、K⁺、通道开放状态和运动方向仍由文本及颜色双重表达。

## 验收标准

- 膜视图源代码包含 `.membrane-channel-art`，Na⁺ 与 K⁺ 使用不同的蛋白精灵位置。
- 粒子和流动点引用 `transmitters-layer.png`，通道引用 `receptors-layer.png`。
- 时间轴定位到 2.5 和 4.5 时，原有离子流路径、通道开放状态和方向测试继续通过。
- 关闭与开放通道具有可测试的 `data-open` 状态，并通过样式产生不同视觉表现。
- 独立成品中包含两个素材文件且生产构建通过。
