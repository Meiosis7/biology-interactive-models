# 动作电位的形成和传导：动态交互模型设计

## 1. 项目定位

本模型是“选择性必修 1 交互模型”系列的第 1 个主题，服务于高中生物课堂演示与学生自主探究。内容严格控制在高中课程范围，不引入复杂的离子通道动力学方程。

模型采用“双视图联动”方案：神经纤维动画负责呈现动作电位的形成与传播，膜电位曲线负责呈现记录点随时间发生的电位变化。两部分由同一时间状态驱动，离子流、通道开合、传播位置、曲线游标和解释文字保持同步。

## 2. 学习目标

学生完成交互后应能：

1. 说出静息电位、去极化、反极化、复极化和恢复阶段的膜电位变化。
2. 将去极化与 Na⁺ 内流、复极化与 K⁺ 外流正确对应。
3. 理解达到阈值后动作电位具有“全或无”特征。
4. 解释兴奋如何通过局部电流使相邻部位依次兴奋。
5. 判断离体神经纤维中部受刺激后，兴奋可向两侧传播。
6. 理解记录电极位置会影响动作电位被记录到的时间，但不改变单个动作电位的幅度。

## 3. 页面结构

模型为单页面交互实验台，由以下区域组成：

### 3.1 顶部任务区

- 标题：“动作电位的形成和传导”。
- 任务提示：“给予神经纤维适宜刺激，观察动作电位如何形成并传播。”
- 简短说明当前实验条件，例如“离体神经纤维，中部刺激”。

### 3.2 神经纤维主视图

- 横向展示一段神经纤维及膜内、膜外区域。
- 显示代表性的 Na⁺、K⁺ 粒子和相应离子通道。
- 用通道开合、离子运动方向和局部颜色变化表现膜电位状态。
- 兴奋区域用暖黄色光带表示，随时间向未兴奋区域传播。
- 可选择左侧、中部或右侧作为刺激位置。
- 可拖动记录电极，设置下方曲线的记录位置。
- 中部刺激时，传播光带向两侧移动，并明确标注“离体神经纤维实验情境”。

### 3.3 膜电位曲线

- 横轴为时间，纵轴为膜电位，单位 mV。
- 关键参考值为静息电位约 −70 mV、阈电位参考线和峰值约 +30 mV。
- 曲线包含静息、去极化、反极化、复极化和恢复阶段。
- 时间游标与主视图动画同步。
- 当前阶段在曲线中高亮，并显示阶段名称。
- 未达到阈值时仅绘制局部电位，不出现完整动作电位。

### 3.4 阶段解释卡

解释卡随时间状态更新，固定包含三项：

- 电位变化。
- 主要离子运动。
- 形成原因。

解释使用高中教材语言，避免将示意动画描述成离子数量或速率的精确测量。

### 3.5 控制区

- “开始刺激”按钮。
- 播放/暂停按钮。
- 上一步、下一步按钮。
- 重置按钮。
- 可拖动时间轴。
- 刺激强度控制，至少包含“弱刺激”“阈刺激”“强刺激”三个清晰档位。
- 刺激位置控制：左侧、中部、右侧。
- 动画速度控制：慢速、正常。

## 4. 状态与联动规则

模型使用统一时间状态驱动所有视觉和文字反馈：

1. 用户设置刺激强度、刺激位置与记录电极位置。
2. 开始刺激后，根据刺激强度判断是否达到阈值。
3. 阈下刺激只在刺激位置产生短暂局部电位，不启动传播。
4. 阈刺激和强刺激均启动同幅动作电位；强刺激不提高单个动作电位的峰值。
5. 兴奋传播到记录电极所在位置时，曲线才进入完整动作电位阶段。
6. 拖动时间轴、单步或自动播放都会更新同一时间状态。
7. 主视图、曲线游标、阶段高亮和解释卡读取同一状态，因此不会出现不同步。
8. 改变刺激位置、强度或记录点后，当前实验自动回到初始状态，防止旧结果与新设置混合。

## 5. 教学时间线

### 5.1 静息状态

- 膜电位约为 −70 mV，膜外相对为正、膜内相对为负。
- 不展示明显的跨膜离子流动画。

### 5.2 达到阈值

- 刺激位置首先变化。
- Na⁺ 通道开始开放，显示 Na⁺ 向膜内移动。

### 5.3 去极化与反极化

- 膜内电位快速升高，曲线越过 0 mV 并接近 +30 mV。
- Na⁺ 内流是这一阶段的主要离子变化。

### 5.4 复极化

- Na⁺ 通道关闭或进入不开放状态。
- K⁺ 通道开放，显示 K⁺ 向膜外移动。
- 膜电位下降。

### 5.5 恢复静息

- 膜电位回到约 −70 mV。
- 动画停止强调跨膜离子流，恢复静息状态外观。

### 5.6 兴奋传播

- 已兴奋部位与相邻未兴奋部位之间形成局部电流。
- 相邻部位依次达到阈值并产生动作电位。
- 视觉上表现为局部膜状态依次变化，而不是同一批离子沿整条神经纤维移动。

## 6. 防误解设计

模型明确处理以下常见误解：

- 不把动作电位传播表现为 Na⁺ 或 K⁺ 沿轴突进行长距离移动。
- 阈刺激和更强刺激产生的单个动作电位幅度相同，以体现“全或无”。
- Na⁺ 内流和 K⁺ 外流的主要阶段分开呈现，不让二者同时达到视觉峰值。
- 明确“双向传播”对应离体神经纤维中部受刺激的实验条件。
- 粒子数量、通道数量和动画速度均为教学示意，不代表真实比例。

## 7. 视觉与动效

- 整体采用深蓝色实验台背景。
- Na⁺ 使用青色，K⁺ 使用紫色。
- 兴奋区域使用暖黄色。
- 膜电位曲线使用红橙色。
- 动效限于通道开合、离子跨膜移动、传播光带和曲线游标。
- 状态同时由文字、图形和颜色表达，避免只依赖颜色。
- 自动播放可随时暂停；禁用持续闪烁和无法停止的装饰动画。

## 8. 响应式与可访问性

- 优先适配电脑投屏和平板横屏。
- 小屏幕上将主视图、曲线和解释卡纵向排列，控制项保持可点击。
- 所有按钮提供可读标签、键盘焦点样式和禁用状态。
- 时间轴支持键盘调整。
- 颜色对比满足清晰阅读需要；关键信息不只通过颜色传递。
- 尊重系统“减少动态效果”设置，降低非必要过渡动画。

## 9. 验收标准

### 9.1 教学正确性

- 弱刺激不会产生或传播完整动作电位。
- 阈刺激与强刺激产生相同峰值的单个动作电位。
- 去极化主要显示 Na⁺ 内流，复极化主要显示 K⁺ 外流。
- 中部刺激产生双向传播；端部刺激主要沿神经纤维向另一端传播。
- 记录点距离刺激点越远，记录到动作电位的时间越晚，幅度不变。

### 9.2 交互完整性

- 播放、暂停、单步、时间轴拖动和重置均能稳定工作。
- 三种刺激位置和记录电极位置均能正确影响传播与记录时间。
- 改变实验设置后不会残留上一轮实验状态。

### 9.3 视图同步

- 神经纤维状态、膜电位曲线、游标、阶段名称和解释卡始终一致。
- 自动播放、手动单步和拖动时间轴得到相同状态结果。

### 9.4 显示质量

- 电脑、平板横屏和常见手机宽度下无内容遮挡或不可操作控件。
- 暂停动画后，所有信息仍可被静态理解。

## 10. 范围边界

首版不包含有髓神经纤维的跳跃传导、绝对不应期与相对不应期的定量分析、Hodgkin–Huxley 方程、真实电导曲线、连续刺激频率编码或实验数据导出。这些内容可在后续需要时作为独立扩展，不影响本模型的核心结构。

## 11. Final-review amendments（2026-08-06）

本节优先级高于前文中与之冲突的固定时长、端部单向波前和物理秒数表述：

1. 实验总时长不再固定为 10。阈刺激和强刺激的时长由当前刺激点到记录电极的到达时间加上完整 6 个局部波形时间单位派生，并向上取整到 0.5 时间单位；弱刺激和近距离情形采用 8 个时间单位的合理下限。播放停止、时间轴、单步边界和曲线横轴共用同一派生值。
2. 神经纤维内部任意刺激点都产生左右两个传播波前。较短一侧先到达并夹紧在边界，较长一侧继续传播；因此原“左/右端只显示单波前”的实现与验收描述作废。
3. 轴突上的通道和粒子按各自空间位置派生局部快照，不再由记录电极快照统一驱动。记录电极快照只负责曲线、当前读数与解释卡；弱刺激即使未被远处电极记录，也须在刺激附近显示局部 Na⁺ 通道反应。
4. 局部电位、达到阈值和去极化阶段统一对应 Na⁺ 内流/通道开放；反极化阶段文案改为 Na⁺ 通道逐渐关闭、K⁺ 通道随后开放，与轴突图形状态一致。
5. 播放状态必须控制离子 CSS 动画。暂停、单步和拖动时间轴时，通道状态仍可静态显示，但离子不得持续运动。
6. 时间统一称为“教学时间（时间单位）”。界面明确说明动画时间和传播速度为教学示意，不对应真实生理秒数。
7. 曲线必须显示教学时间刻度、文字化的 −55 mV 阈电位参考、当前阶段名称和完整无障碍摘要；Canvas 使用明确的响应式 CSS 高度，确保 ResizeObserver 与 DPR 重绘不受历史 backing-buffer 尺寸影响。
