# 膜电位网页播放修复与手机单屏设计

## 范围

只修改现有膜电位变化网页。忽略本轮附带的 PDF，不读取、不引用，也不改变知识内容。

## 已确认的播放故障

源代码中的播放按钮能切换运行状态，时间推进也由 `requestAnimationFrame` 驱动。公开网页失效的直接原因是上次 GitHub Pages 发布遗漏了两个被页面引用的 JavaScript 文件，线上返回 404，导致 React 没有完成客户端接管，按钮只能显示但无法响应。

修复分两层：

1. 立即补齐缺失的运行文件，恢复当前公开页交互。
2. 新版发布必须验证 HTML 引用的每一个脚本都返回 HTTP 200，避免再次出现静态页面可见但无法操作的情况。

## 手机单屏布局

手机宽度不采用左右双栏，也不采用曲线/通道分页切换。页面在 `max-width: 800px` 时固定为一个 `100svh` 视角，并保持以下纵向顺序：

1. 紧凑标题与当前状态；阶段、电位、离子流同一行显示。
2. 主过程区占据剩余高度，上半部为逐步形成的电位曲线，下半部为膜两侧离子、Na⁺/K⁺ 通道及跨膜方向动画。
3. 当前阶段说明压缩为阶段按钮条和一行“通道与离子”摘要。
4. 控制台压缩为两行：刺激强度与播放/重置在第一行，时间轴在第二行。倍速和对比曲线在手机端隐藏，桌面端继续保留。

页面禁止纵向滚动，所有区域使用 `minmax(0, 1fr)` 和内容压缩规则，避免固定像素高度把下方内容推出视角。短屏手机进一步隐藏次要副标题并缩小间距，但保留曲线、离子通道、当前离子流、刺激强度、播放和时间轴。

## 桌面端

桌面单视角布局、全部阶段说明、倍速和曲线对比功能保持不变。

## 验收标准

- 公开网页引用的所有 JavaScript 文件返回 HTTP 200。
- 点击“开始”后按钮变为“暂停”，时间、电位、曲线与离子状态持续推进。
- 800px 及以下视图使用 `height: 100svh` 和 `overflow: hidden`，不产生整页纵向滚动。
- 同一手机视角内可见电位曲线、膜/通道与离子信息、刺激强度、播放/重置和时间轴。
- 桌面布局与现有交互测试不退化。
