# 神经类模型基础引导与点击逻辑复查设计

## 目标

降低动作电位、突触传递、膜电位曲线和电表偏转四个模型的首次学习难度，同时保留原有完整实验能力。复查首页与六个模型的全部点击路径，确保鼠标、键盘和触屏操作一致可靠。

## 方案选择

采用“默认基础引导 + 可展开进阶模式”。相比直接删减参数，这能让初学者先理解核心因果关系，也不会损失教师演示和复习时需要的完整功能；相比额外制作两套页面，共用同一套模拟状态可避免内容不一致。

备选方案包括：只改文案但保留全部控件，以及拆成独立的基础版/进阶版页面。前者不足以降低操作负担，后者会增加维护和学习路径切换成本，因此不采用。

## 统一交互结构

四个神经模型都提供一致的学习入口：

1. 顶部显示一句“本页只需看懂什么”。
2. 基础引导用三步表达：先操作、再观察、最后得出结论。
3. 每一步只突出一个主操作，其余控制保持可用但降低视觉权重。
4. 专业术语旁提供一句白话解释，不用术语堆叠说明术语。
5. “进阶模式”展开后显示原有刺激位置、速度、时间轴、预设、推理过程等完整控制。
6. 重置会回到第一步和默认基础状态；切换模式不丢失当前模拟状态。

## 各模型简化重点

### 动作电位

默认使用适宜刺激和中部刺激，只突出“开始刺激”。引导依次观察膜内外电位变化、动作电位形成、兴奋向两侧传播。弱刺激、阈刺激、刺激位置、速度和时间轴放入进阶区。阶段卡先显示白话结论，再显示离子通道解释。

### 突触传递

引导依次观察突触前膜释放递质、递质跨过突触间隙、突触后膜产生变化。默认突出“开始传递”和“下一步”。反向刺激、播放速度和自由时间控制放入进阶区，同时明确化学突触只能单向传递。

### 膜电位曲线

把曲线拆成“静息—上升—下降—恢复”四个观察点，点击阶段标签即可定位。默认题目只考阶段与离子流向的直接对应；弱刺激形成局部电位及完整曲线探究保留在进阶区。

### 电表偏转

默认先用“膜外双电极（A 先到）”示范，只要求判断首次偏转方向和原因。随后再给 B 先到、跨膜和等距验证。基础区显示“谁先兴奋 → 两电极电位差 → 指针方向”的三段因果链，完整推理开关与自由时间控制放入进阶区。

## 点击逻辑复查

复查范围包括：首页六张入口卡、模型间上一个/下一个导航、全部模式与预设按钮、开始/暂停/继续、上一步/下一步、重置、时间滑块、阶段标签、题目选项、答案反馈和进阶区开关。

每个控件检查：点击后的唯一预期状态、重复点击、边界禁用、播放结束、重置恢复、模式切换保留状态、键盘激活、触屏尺寸以及不会误触相邻控件。页面直达和刷新后必须落在可操作的初始状态。

## 状态与错误处理

引导步骤只从模拟快照派生，不另建一套与动画脱节的状态。超出时间边界时钳制到起点或终点；播放结束自动停止；不可执行的步骤明确禁用。反馈区只播报阶段变化和答题结果，避免连续动画造成读屏噪声。

## 验证标准

- 四个神经模型首次进入时，用户不展开进阶区即可完成一轮核心学习。
- 所有原功能仍可在进阶区使用。
- 六个模型和首页的关键点击路径均有自动测试。
- 桌面端与手机尺寸实测无横向溢出，所有主要触控目标不小于 44 像素。
- 全量测试、代码检查和正式构建通过，浏览器控制台无新增错误。
