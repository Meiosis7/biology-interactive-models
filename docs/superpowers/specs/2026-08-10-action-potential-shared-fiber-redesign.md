# 动作电位同图三模式改版设计

## 目标

参考用户提供的教材示意图，重新制作“动作电位的形成和传导”页面。页面保留三个独立模式，但三个模式必须共用同一张横向圆柱形神经纤维图。切换模式时神经纤维的位置、尺寸和观察角度不变，仅改变膜两侧电荷、离子运动、兴奋区、局部电流和教学标注。

页面继续排除膜电位曲线、坐标轴、膜电位数值、记录电极、刺激强度、时间轴和进阶实验控件。

## 页面结构

页面由四部分组成：

1. 标题和一句操作提示；
2. “静息电位、动作电位产生、动作电位传导”三个并列模式按钮；
3. 共用的神经纤维主图；
4. 与当前模式同步的知识卡和播放控制。

桌面端采用主图与知识卡左右排列。手机端三个模式按钮保持同一行，主图与知识卡上下排列。所有按钮点击区域高度不小于 44 像素，390 像素宽度下不得产生横向滚动。

## 共同神经纤维图

三个模式使用同一个视觉组件和同一套几何结构：

- 一根横向圆柱形神经纤维；
- 上方固定表示膜外，下方固定表示膜内；
- 膜上分布 Na⁺ 通道和 K⁺ 通道；
- 电荷符号、离子、箭头、刺激点和兴奋区作为状态图层叠加；
- 模式切换不改变神经纤维的尺寸、位置或观察角度。

视觉采用接近参考图的浅色教材示意风：背景为柔和白色或浅灰纸张色，神经纤维以灰色线稿和轻微立体阴影呈现，正文使用深灰色，关键电性和结论使用红色，Na⁺ 与 K⁺ 使用两种稳定且易区分的辅助色。页面不直接复制参考图中的图片素材或排版，而是重建适合交互网页的教学图。

## 三个模式

### 静息电位

共同神经纤维图呈现：

- 膜外为正、膜内为负；
- K⁺ 通过 K⁺ 通道向膜外运动；
- 图中固定标注“外正内负”和“K⁺ 外流”。

知识卡展示：

- 膜两侧电性：外正内负；
- 主要离子运动：K⁺ 外流；
- 结果：形成并维持静息电位。

### 动作电位产生

共同神经纤维图只展示动作电位产生，不展示恢复静息：

1. 中央刺激点出现；
2. 中央局部 Na⁺ 通道开放；
3. Na⁺ 通过通道向膜内运动；
4. 中央局部由外正内负变为外负内正；
5. 动画停留在局部兴奋状态。

本模式不得展示 K⁺ 外流、恢复外正内负或“恢复静息状态”等内容。

知识卡展示：

- 刺激后的变化：Na⁺ 通道开放；
- 主要离子运动：Na⁺ 内流；
- 结果：局部形成外负内正的动作电位。

### 动作电位传导

共同神经纤维图呈现：

- 神经纤维分为“未兴奋区—兴奋区—未兴奋区”；
- 未兴奋区保持外正内负，兴奋区显示外负内正；
- 兴奋区与相邻未兴奋区之间显示局部电流；
- 两个兴奋波前从中央刺激点向左右两侧移动；
- 图中标注“刺激点”“兴奋区”“未兴奋区”和“双向传导”。

知识卡展示：

- 传导基础：兴奋区与未兴奋区之间形成局部电流；
- 传导过程：相邻部位依次产生动作电位；
- 结果：离体神经纤维上的兴奋可向刺激点两侧传导。

传导知识卡可补充一句提醒：反射弧中的兴奋整体表现为单向传递，但本图展示的是离体神经纤维上的双向传导。

## 交互规则

- 默认选中“静息电位”并自动播放；
- 点击任一模式后，当前按钮进入选中状态，神经纤维图切换状态并从头播放；
- 模式切换重置当前动画进度，不保留上一模式的视觉叠影；
- “播放/暂停”只控制当前模式；
- “重新播放”将当前模式进度归零并开始播放；
- 静息模式循环展示 K⁺ 外流；
- 产生模式播放至外负内正后停留，不循环到恢复静息；
- 传导模式循环展示两个兴奋波前向两侧移动；
- 用户开启减少动态效果时，每个模式显示最有代表性的静态关键帧，模式切换和知识卡仍正常工作。

## 组件与数据边界

- `ActionPotentialLab`：管理当前模式、播放状态、动画进度和减少动态效果；
- `ActionPotentialModeNav`：渲染三个模式按钮；
- `ActionPotentialScene`：只渲染一套共同神经纤维几何结构，并根据动画帧切换状态图层；
- `ActionPotentialKnowledgeCard`：展示当前模式的教学要点；
- `LabControls`：提供播放/暂停和重新播放；
- `modeData.ts`：集中定义三个模式的标题、说明和三个知识点；
- `simulation.ts`：用纯函数把模式与归一化进度转换为电性、离子运动、开放通道、兴奋区位置和局部电流状态。

视觉组件不得自行推进时间或修改模式。动画循环只推进归一化进度，所有教学文案从集中模式数据读取。

## 验收与测试

自动化测试覆盖：

- 默认选中静息电位；
- 页面恰好显示三个模式按钮；
- 三个模式使用同一个神经纤维结构，不渲染三张独立主图；
- 切换模式会重置动画并更新知识卡；
- 静息模式显示外正内负和 K⁺ 外流；
- 产生模式依次显示刺激、Na⁺ 内流和局部外负内正；
- 产生模式不出现 K⁺ 外流、恢复静息或恢复阶段；
- 传导模式显示未兴奋区、兴奋区、局部电流和两个向外移动的波前；
- 页面不出现膜电位曲线、坐标轴和任何膜电位数值；
- 播放、暂停和重新播放逻辑正确；
- 减少动态效果时显示正确静态信息；
- 390 像素宽度下无横向溢出，所有按钮高度不小于 44 像素；
- 全部测试、代码检查和生产构建通过；
- 桌面端与手机端实际点击三个模式，浏览器控制台无错误。
