# 膜电位模型手机端防遮挡设计

## 目标

让 800px 及以下宽度的手机和平板竖屏视图按自然文档流完整展示，不再让曲线、膜结构、阶段说明、状态栏或操作区互相覆盖，同时保持桌面单视角布局和全部交互逻辑不变。

## 已确认原因

- 手机断点中，曲线卡片仍使用固定的 310px 网格行高。
- 膜结构卡片固定为 420px，同时内部场景最小高度为 330px；标题、图例和说明增加高度时，父容器无法自然扩展。
- 顶部状态栏的三个状态项保持单行弹性布局，窄屏中文案会被挤压。
- 图表标题、膜结构标题和底部选项缺少明确的换行策略。

## 设计

- 手机端继续保持“曲线 → 膜结构 → 分步说明 → 操作区”的纵向顺序。
- 曲线和膜结构卡片取消固定父容器高度；两个可视区域分别使用受控的响应式高度，卡片自身由内容自然撑开。
- 顶部状态栏改成两列网格：阶段和电位位于第一行，离子流信息占第二整行。
- 标题、图例和操作选项允许换行；超窄屏下标题与实时状态也改为上下排列。
- 桌面端和中等宽度布局规则不变。

## 验收标准

- 手机断点中不存在膜结构卡片 `height: 420px` 或场景 `min-height: 330px` 的组合。
- 手机状态栏能分两行显示，离子流信息占满第二行。
- 曲线标题、膜结构标题和选项区允许换行。
- 所有现有自动化测试与构建通过。
- GitHub Pages 公开网页发布新样式并可正常访问。
