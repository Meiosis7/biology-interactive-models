# 动作电位传导文案精简设计

## 目标

精简动作电位传导模式中的过程文案，避免“第1轮、第2轮、第3轮”和“当前第几步”分散学生对局部电流与动作电位交替形成过程的注意力。

## 文案规则

- 三个 `local-current` 宏观步骤的画面提示全部固定为“形成局部电流”。
- 不显示“第1轮局部电流形成”“第2轮局部电流形成”或“第3轮局部电流形成”。
- 传导控制区只显示“下一步”和“重新演示”两个按钮，不显示“当前第几步，共7步”“本步动画播放中”或“传导演示完成”等状态段落。
- 传导尚未完成时，不显示底部“兴奋由刺激点向两侧逐段传导”及其装饰箭头。
- 七段全部兴奋后，继续在底部显示最终结论：“神经冲动以电信号（局部电流）的形式在神经纤维上双向传导。”

## 保留内容

- 七步手动点击顺序、按钮禁用时机、局部电流绘制、Na⁺通道开放和双侧内流动画不变。
- 产生模式循环、静息模式、四层电荷、共轴通道和开放式纤维两端不变。
- 最终状态仍禁用“下一步”，并保留“重新演示”。
- `aria-live` 的阶段说明仍由场景顶部提示承担，不新增隐藏的轮次或步数文案。

## 验收标准

- 三个局部电流步骤顶部均只显示“形成局部电流”。
- 页面任何可见位置均不出现“第1轮”“第2轮”“第3轮”“当前第”“共7步”“本步动画播放中”或“传导演示完成”。
- 非终态不显示底部传导句；终态只显示一次完整最终结论。
- “下一步”和“重新演示”的功能、禁用状态及七步传导结果无回归。
- 桌面与移动端均无因删除文案产生的多余空白、溢出或布局错位。
