# 电表指针偏转问题：动态交互模型设计

## 1. 学习目标

学生完成模型后应能：

1. 根据两个记录电极所在位置判断电位差随时间的变化。
2. 判断兴奋依次经过两电极时指针偏转方向和次数。
3. 区分膜外双电极、膜内外跨膜记录和等距记录情境。
4. 理解指针方向取决于两端电势差和接线方向，不靠死记左右偏转。
5. 判断刺激点、电极间距和兴奋传播方向对记录结果的影响。

## 3. 记录模式

- 膜外双电极：A、B 均位于膜外，重点研究两次相反偏转、一次偏转或不偏转。
- 膜内外跨膜：一端膜内、一端膜外，重点显示静息时已有稳定电位差及兴奋后的变化。
- 等距验证：刺激点位于 A/B 中点，两点同时兴奋，理想对称情况下电位差相抵。

## 4. 交互设置

- 拖动刺激点、A 电极、B 电极。
- 交换电表正负接线。
- 选择记录模式。
- 播放、暂停、单步、教学时间轴、慢速/正常、重置。
- “推理提示”开关：依次展示两点状态、代入电位差、判断方向；关闭时保留自主作答。

## 5. 指针逻辑

- 指针角度由当前 `V_A − V_B` 的符号和大小派生。
- 当 A、B 同处静息或同处等幅兴奋状态时，膜外双电极电位差接近零，指针回到中央。
- 兴奋先到 A、后到 B 时，产生两次方向相反的偏转；交换接线后方向整体相反。
- 若兴奋同时到达 A、B，理想对称示意下不发生明显偏转。
- 当刺激点位于两个电极之外，传播顺序由距离决定；模型不使用固定“先左后右”规则。

## 6. 防误解设计

- 屏幕始终显示接线定义和电位差公式。
- 用“向正接线端对应方向/向负接线端对应方向”解释，不把“左偏”“右偏”作为脱离接线的结论。
- 指针运动为示意，不模拟真实检流计惯性。
- 单次动作电位沿神经纤维传播时幅度不随距离衰减。

## 7. 验收标准

- 拖动任意一个位置后，传播顺序、曲线和指针结果同步更新。
- 交换接线可反转指针方向，但不改变兴奋到达顺序。
- 等距情境显示同步到达和近零电位差。
- 暂停后波前和指针停止。
- 预置至少四个典型题型，并允许自由摆放电极。
