# 动作电位模型视觉与动画优化设计

日期：2026-08-11

## 1. 目标

在不改变已经确认的三模式教学逻辑的前提下，重新设计动作电位模型的视觉表现与动画质感，使通道开闭方向准确、离子运动自然、传导接力清楚，并达到适合课堂投屏的浅色教材动画效果。

## 2. 保持不变的教学范围

- 保留三个模式：静息电位、动作电位产生、动作电位传导；
- 三个模式继续复用同一根水平神经纤维；
- 继续使用七段膜区，中央第 4 段为刺激位置；
- 静息模式表现 K⁺外流；
- 产生模式表现刺激、中央 Na⁺通道开放、Na⁺内流、中央局部外负内正；
- 传导模式表现局部电流和相邻 Na⁺通道逐段开放；
- 已兴奋膜段只增加，不恢复为静息状态；
- 不加入膜电位曲线、电压数值、复极化、超极化或恢复过程；
- 保留三个模式按钮、播放/暂停和重新播放。

## 3. 当前问题与根因

### 3.1 通道开启方向错误

当前通道由上下排列的两个门体组成，开放状态通过 `translateY()` 让上半部向上、下半部向下移动。这会形成“上下开启”的视觉，与用户要求和参考视频中的左右门瓣开启不一致。

新的通道必须采用左右两瓣结构：关闭时两瓣在中央接合，开启时左瓣向左、右瓣向右分开，中央孔道显露。开放动画不得使用上下分离作为主要动作。

### 3.2 视觉层级偏机械

当前神经纤维使用大面积灰色圆柱、强边框和分段色块，通道与离子以小图标叠加，整体像机械管道，缺少教材插图的清楚层级。

新的视觉应突出“膜、通道、离子、局部电流、兴奋区”五类教学对象，减少不必要的灰色重量感。

### 3.3 动画表达生硬

当前离子运动以单个胶囊文字上下位移表示，局部电流主要依赖静态字符箭头。新的动画需要让通道开启、离子穿孔、目标膜段提示和膜段兴奋形成连续因果链。

## 4. 整体视觉风格

采用浅色教材动画风格：

- 页面背景保持米白或浅灰白；
- 场景卡片使用白色或暖白色，配柔和边框与轻阴影；
- 主文字使用深灰绿色，避免纯黑；
- 膜结构使用低饱和蓝灰与暖白，不再使用厚重深灰圆柱；
- Na⁺使用蓝绿色；
- K⁺使用紫色；
- 刺激使用橙红色；
- 兴奋膜段使用淡珊瑚红或淡粉红；
- 待兴奋目标使用淡蓝呼吸光，不提前改变膜电性；
- 所有颜色同时配文字或形态差异，不只靠颜色传达状态。

## 5. 神经纤维与膜段

- 保持水平长条结构和七个等宽膜段；
- 用上下两条细膜带表达膜外边界和膜内边界，中间为浅色膜内区域；
- 七段之间只使用轻微分隔线，保证整体仍像一根连续神经纤维；
- 静息段显示外正内负；
- 兴奋段显示外负内正，并通过淡红底色与细描边增强识别；
- 当前目标段使用蓝色柔光轮廓，但电荷保持静息状态，直到 Na⁺内流完成；
- 两端使用柔和圆角，不使用强烈立体圆柱端盖。

## 6. 离子通道设计

### 6.1 结构

每个 Na⁺通道由以下部分组成：

- 左门瓣；
- 右门瓣；
- 中央孔道；
- 通道底座或膜内嵌区域。

左右门瓣使用独立元素或伪元素，不再使用上下两半结构。

### 6.2 关闭状态

- 左右门瓣在中央接合；
- 中央孔道被遮挡或收窄；
- 通道轮廓稳定，不上下跳动；
- 无离子穿过。

### 6.3 开放状态

- 左门瓣向左平移约 5–7px，并轻微逆时针旋转；
- 右门瓣向右平移约 5–7px，并轻微顺时针旋转；
- 中央孔道清楚显露；
- 开启动画约 280–320ms，使用平滑的 ease-out；
- 可增加轻微蓝色外发光，但不得遮挡电荷或离子标签。

K⁺通道使用同一左右开启机制，以紫色区分；静息模式中保持开放。

### 6.4 方向验收

通道关闭与开启的几何中心保持不变。开放前后：

- 左门瓣的水平坐标减小；
- 右门瓣的水平坐标增大；
- 两瓣的垂直中心基本不变；
- 中央水平间距明显增大；
- 不得通过一瓣向上、一瓣向下制造主要开放效果。

## 7. 离子动画

### 7.1 离子造型

- 使用 2–3 个小圆形离子球，而不是单个长胶囊；
- 圆球内或旁边显示 `Na⁺`、`K⁺`；
- Na⁺离子球为蓝绿色，K⁺离子球为紫色；
- 离子大小足以在投屏和 390px 移动端识别，但不遮挡通道门瓣。

### 7.2 Na⁺内流

- 离子从膜外通道上方开始；
- 依次穿过左右门瓣之间的中央孔道；
- 最终进入对应膜段内部；
- 2–3 个离子使用约 120ms 的错峰；
- 单个离子运动约 650–850ms；
- 轨迹以垂直穿孔为主，可有极轻微横向弧度；
- 可使用低透明度拖尾，但不得形成电位曲线或长光带。

### 7.3 K⁺外流

- 使用相同的离子球结构；
- 运动方向从膜内穿过开放的 K⁺通道到膜外；
- 循环节奏比 Na⁺内流略慢，强调静息模式的稳定状态。

### 7.4 暂停与终点

- 暂停时离子停留在当前视觉位置；
- 离子动画在暂停时使用 `animation-play-state: paused` 保留当前进度，不通过移除 `animation` 属性让离子跳回起点；
- 产生和传导终点停止离子循环，不继续无限穿孔；
- 重新播放后重置对应动画实例，使离子从阶段起点重新出现。

## 8. 传导动画

每轮接力由四个视觉动作组成：

1. **目标提示**：左右相邻未兴奋膜段出现淡蓝呼吸光；
2. **局部电流**：膜内流动方向由兴奋区指向目标段，膜外回流方向相反；
3. **通道开启与离子内流**：目标段 Na⁺通道左右门瓣打开，多个 Na⁺依次穿孔；
4. **膜段兴奋**：目标段由外正内负平滑过渡为外负内正，淡蓝提示消失，淡红兴奋底色出现。

上述动作按 `[2,4] → [1,5] → [0,6]` 三轮推进。中央和先前兴奋膜段始终保持兴奋，不出现恢复动画。

## 9. 局部电流视觉

- 不再把 Unicode 箭头作为主要动效；
- 使用细线或 SVG 路径显示膜内与膜外电流；
- 膜内路径从兴奋区边缘指向左右目标段；
- 膜外路径从目标段返回兴奋区；
- 路径上使用小光点或短虚线沿方向移动；
- 膜内、膜外路径使用不同明度但同一蓝绿色系；
- 保留简短文字标签，确保静态帧也能读懂方向；
- 三轮接力时路径长度随目标距离增长。

## 10. 动效节奏

- 通道开启：约 300ms；
- 目标呼吸提示：约 600–900ms；
- 离子穿孔：约 650–850ms，带错峰；
- 膜段电性与底色变化：约 300ms；
- 步骤之间保留 150–250ms 的短暂停顿；
- 动画使用 ease-out 或 ease-in-out，不使用弹跳、剧烈缩放或快速闪烁；
- 三轮传导总时长保持在约 6 秒，适合课堂观察。

## 11. 响应式与减少动态效果

### 桌面端

- 场景继续作为主视觉；
- 七个通道、离子和电荷均可辨认；
- 当前阶段提示位于图上方，不遮挡动画；
- 知识卡保持次要但清楚。

### 390px 移动端

- 七段全部保留，不隐藏通道；
- 门瓣、离子球和电荷按比例缩小；
- 局部电流文字可精简，但方向线必须可见；
- 不出现横向滚动、通道重叠或离子越界。

### 减少动态效果

- 取消门瓣位移动画、离子穿孔、呼吸光和流动光点；
- 直接显示代表性静态开放状态和离子最终位置；
- 播放与重新播放保持禁用；
- 模式切换继续可用。

## 12. 组件与状态边界

- `simulation.ts` 继续负责教学阶段、目标膜段、开放通道和离子内流状态；
- `ActionPotentialScene.tsx` 负责渲染通道左右门瓣、离子球和局部电流路径；
- CSS 负责视觉造型和暂停/播放/减少动态效果下的动画；
- 不为了视觉优化修改三模式的教学顺序；
- 通道与离子使用稳定的语义标识，便于测试和浏览器验收。

## 13. 测试与验收

### 自动化测试

- 每个膜段仍只有一个 Na⁺通道；
- 通道包含左门瓣、右门瓣和中央孔道；
- 开放状态只改变左右门瓣的水平分离，不依赖上下分离；
- 中央产生阶段只开放中央 Na⁺通道；
- 传导三轮只开放当前目标段通道；
- 离子球只在对应通道开放并发生离子运动时出现；
- 静息模式只显示 K⁺外流；
- 暂停、重播、终点和减少动态效果逻辑保持正确；
- 仍不存在曲线、电压值或恢复相关内容。

### 浏览器视觉验收

- 对比通道关闭与开放状态，确认左右门瓣分别向左和向右移动；
- 测量两瓣垂直中心变化不超过 2px；
- 观察 Na⁺与 K⁺离子确实穿过中央孔道；
- 观察局部电流光点方向与文字含义一致；
- 完整播放产生模式和三轮传导；
- 检查暂停时视觉位置保持；
- 1280×720 和 390×844 均无裁切、重叠或横向滚动；
- 控制台无错误；
- 在真实截图中确认整体为浅色、清楚、适合教材投屏的风格。

## 14. 完成标准

满足以下条件即视为完成：

1. 通道关闭时左右合拢，开启时左右分开，方向无歧义；
2. 离子以多个小球依次穿过打开的孔道；
3. 传导动画形成目标提示、局部电流、通道开启、离子内流、膜段兴奋的连续因果链；
4. 视觉由灰色机械管道改善为浅色教材动画；
5. 三模式逻辑、禁用范围、播放行为和响应式要求全部保持；
6. 自动化与浏览器视觉验收全部通过。
