# 动作电位 PDF 批注修订设计

## 目标

在保留现有三模式、循环播放与手动传导交互的前提下，依据《动作电位的形成和传导 修改.pdf》修正动作电位页面中的教学表述、刺激与膜结构对齐、上下膜通道动画以及移动端呈现。

## 保留内容

- 三个模式：静息电位、动作电位产生、动作电位传导。
- 动作电位产生自动循环播放，可暂停、继续和重新播放。
- 动作电位传导由“下一步”逐步推进，不自动跳到下一教学状态。
- 神经纤维两端保持开放式。
- 每个膜段保留上膜和下膜两套通道及四层电荷位置。

## 页面精简

- 动作电位页面不再显示跨模型的“上一个 / 下一个”导航条。
- 保留页面主标题、三模式按钮、模型动画、播放控件和知识卡。

## 教学文案

### 动作电位产生阶段

阶段提示依次使用：

1. `刺激局部神经纤维`
2. `局部 Na⁺通道开放`
3. `Na⁺从膜外进入膜内`
4. `受刺激部位兴奋，膜外为负、膜内为正`

知识卡统一为：

- 标题：`局部动作电位产生`
- 概述：`刺激使局部 Na⁺通道开放，Na⁺内流，受刺激部位膜外为负、膜内为正。`
- 原因：`刺激局部神经纤维`
- 通道与离子变化：`局部 Na⁺通道开放，Na⁺内流`
- 结果：`受刺激部位膜外为负、膜内为正`

### 动作电位传导阶段

- 初始提示：`受刺激部位已经形成动作电位`
- 局部电流提示：`形成局部电流`
- 相邻通道提示：`局部电流使相邻部位 Na⁺通道开放`
- 内流提示：`Na⁺从上下通道进入相邻部位膜内`
- 兴奋提示：`相邻部位形成动作电位`
- 不出现“第一轮、第二轮、第三轮”或“第几步”的描述。
- 知识卡原因改为：`兴奋部位与未兴奋部位之间形成局部电流`
- 最终结论保持：`神经冲动以电信号（局部电流）的形式在神经纤维上双向传导。`

## 图形与动画

- 每个膜段的电荷、上膜通道、下膜通道共用同一条竖直中心线。
- 刺激标记与受刺激膜段中心对齐，但不得遮挡通道孔或离子。
- 上、下膜 Na⁺通道必须同步开放。
- Na⁺粒子必须经过通道孔进入膜内；在穿膜位置不得横向绕开通道。
- 上膜 Na⁺向下进入膜内，下膜 Na⁺向上进入膜内。
- 静息模式中的 K⁺从上、下膜通道分别向膜外流出。
- 局部电流继续采用四条短弧线：膜内两条由兴奋部位向两侧，膜外两条由未兴奋部位返回兴奋部位；弧线从尾端向箭头端逐渐绘制。
- 传导每次点击只完成一个状态：形成局部电流或相邻部位形成动作电位，然后停住等待下一次点击。

## 电荷状态

- 未兴奋膜段从上到下为：膜外 `＋`、膜内 `−`、膜内 `−`、膜外 `＋`。
- 兴奋膜段从上到下为：膜外 `−`、膜内 `＋`、膜内 `＋`、膜外 `−`。
- 通道开放和 Na⁺内流阶段在动作电位真正形成前保持原电荷状态；兴奋形成后四层电荷同时切换，不能出现膜内外同时为负的中间状态。

## 响应式与可用性

- 桌面端和手机端均完整显示七个膜段，不产生横向滚动。
- 手机端“下一步 / 重新演示”控件保持紧凑并在动画下方就近出现。
- 所有按钮的可点击尺寸不小于 44px。
- 暂停时通道、离子和局部电流动画保持在当前位置，继续后从原位置续播。
- `prefers-reduced-motion` 下提供相同教学状态的静态画面。

## 验收标准

- PDF 中圈出的“中央、中央膜段”不再出现。
- 页面不存在跨模型的上一个/下一个导航。
- 上下膜通道、离子流、电荷与刺激点在两种视口下均正确对齐且互不遮挡。
- 产生模式完整循环，传导模式逐次点击推进并在最终结论处停止。
- 自动化测试、代码检查、生产构建及桌面/手机浏览器验收全部通过后再发布。
