# 动作电位参考视频逻辑重制设计

日期：2026-08-11

## 1. 目标

重制“动作电位的形成和传导”交互模型，使动画顺序与用户提供的教学视频一致，清楚表现离子通道、离子运动、局部膜电性变化和兴奋向相邻部位传导的因果关系。

本次仍保留三个模式，并让三个模式始终使用同一张水平神经纤维图：

1. 静息电位
2. 动作电位产生
3. 动作电位传导

## 2. 明确范围

### 包含

- 静息状态下的外正内负；
- K⁺通道开放与少量 K⁺外流；
- 中央刺激点；
- 中央 Na⁺通道开放与 Na⁺内流；
- 中央膜段由外正内负变为外负内正；
- 兴奋部位与相邻未兴奋部位之间形成局部电流；
- 相邻 Na⁺通道按距离由近到远依次开放；
- 兴奋区域从中央向左右两侧逐段扩大；
- 播放、暂停和重新播放；
- 桌面端与移动端适配，以及减少动态效果的静态关键帧。

### 不包含

- 膜电位变化曲线；
- 电压数值、坐标轴或阈值数值；
- 动作电位产生后的 K⁺外流、复极化或超极化；
- 恢复为静息电位；
- 传导过程中已兴奋部位的恢复；
- 钠钾泵、ATP 或更深入的通道失活机理；
- 速度调节、时间轴或额外高级控制。

## 3. 教学逻辑

### 3.1 静息电位

同一根神经纤维被划分为七个连续膜段。所有膜段均显示外正内负。Na⁺通道保持关闭；K⁺通道开放，并在代表性的 K⁺通道处循环显示少量 K⁺从膜内向膜外移动。

静息模式只解释静息电位的主要离子基础，不引入曲线、毫伏数值或钠钾泵细节。

### 3.2 动作电位产生

动画只在中央膜段发生，按以下顺序播放并最终停住：

1. 中央出现刺激标记，全部膜段仍为外正内负；
2. 中央电压门控 Na⁺通道打开；
3. 多个 Na⁺从膜外穿过中央通道进入膜内；
4. 中央膜段变为外负内正，并标记为“兴奋区”；
5. 动画停在中央局部兴奋状态。

本模式不出现 K⁺外流，也不恢复静息状态。重新播放会从刺激出现之前开始。

### 3.3 动作电位传导

传导动画从“中央膜段已经兴奋”开始，不再重复完整的产生动画。神经纤维左右对称地按距离分为三层相邻膜段。

每一轮接力包含两个清楚可见的步骤：

1. **形成局部电流**：膜内电流从中央或已兴奋边缘指向左右相邻未兴奋区；膜外回流方向相反，指回兴奋区。
2. **相邻部位兴奋**：左右两侧最近的 Na⁺通道打开，Na⁺内流，对应膜段由外正内负变为外负内正。

上述步骤由近到远重复三轮，直到兴奋区域从中央扩展到神经纤维两端。先前已经兴奋的膜段继续保持外负内正，不在动画后方恢复。因此画面表现为“兴奋区域逐段扩大”，而不是两个孤立光点平移，也不是兴奋波后方恢复的脉冲。

## 4. 视觉结构

### 4.1 共用神经纤维

- 三个模式复用同一个场景组件和同一个神经纤维节点；
- 神经纤维采用水平长条膜结构，明确标出“膜外”和“膜内”；
- 七个连续膜段使用轻微分隔线区分，但整体仍是一根连续神经纤维；
- 每个膜段都包含一个可开闭的 Na⁺通道；静息模式另显示代表性的 K⁺通道；
- 通道使用明确的“打开/关闭”形态，而不只依赖颜色差异。

### 4.2 离子与电性

- Na⁺和 K⁺使用不同颜色与文字标签；
- 离子穿过通道时使用短距离、方向明确的移动；
- 未兴奋膜段显示外正内负；
- 兴奋膜段显示外负内正；
- 电荷变化只发生在对应膜段，不整体翻转整根纤维。

### 4.3 局部电流

- 膜内箭头方向与兴奋传导方向相同：从兴奋区边缘指向相邻未兴奋区；
- 膜外箭头方向与传导方向相反：从未兴奋区指回兴奋区；
- 当前将要兴奋的相邻膜段使用淡色提示，但不提前改变电性；
- 文字提示按当前步骤切换为“形成局部电流”或“相邻 Na⁺通道开放”。

## 5. 状态模型

场景不再使用两个连续坐标表示传导中的兴奋中心，而改用离散膜段状态。

每一帧至少包含：

- 当前模式与阶段；
- 七个膜段各自的电性状态：静息或兴奋；
- 七个 Na⁺通道各自的开闭状态；
- K⁺通道状态；
- 当前发生 Na⁺内流或 K⁺外流的膜段；
- 刺激是否可见；
- 局部电流是否可见及其作用边界；
- 当前教学提示。

`getActionPotentialFrame(mode, progress)` 继续作为纯函数，根据模式和归一化进度生成完整画面状态。组件只负责渲染，不自行推断教学阶段。

## 6. 时间与控制

- 静息模式循环播放 K⁺外流；
- 产生模式单次播放并停在中央兴奋状态；
- 传导模式单次播放并停在全段兴奋状态，避免循环时突然跳回中央造成误解；
- 暂停后保持当前画面；
- 重新播放从当前模式的起点开始；
- 切换模式时立即重置并播放新模式；
- 减少动态效果时不自动播放，展示各模式最有代表性的静态关键帧，并禁用播放和重新播放。

## 7. 文案

知识卡与画面提示使用以下核心表述：

- 静息：`K⁺外流，膜两侧保持外正内负`；
- 产生：`刺激使局部 Na⁺通道开放，Na⁺内流，局部外负内正`；
- 传导：`兴奋区形成局部电流，使相邻 Na⁺通道依次开放`；
- 传导结果：`兴奋由刺激点向两侧逐段传导`。

不得出现“兴奋区自己移动”“电荷沿纤维流动”或“动作电位整体平移”等容易造成错误理解的表述。

## 8. 测试与验收

### 状态测试

- 静息模式所有膜段均为静息电性，Na⁺通道关闭，K⁺通道开放；
- 产生模式严格按刺激、中央 Na⁺通道开放、Na⁺内流、中央膜段兴奋推进；
- 产生模式终点只有中央膜段兴奋，且没有 K⁺外流或恢复阶段；
- 传导模式从中央兴奋开始；
- 每次接力先显示局部电流，再让相邻 Na⁺通道开放并新增兴奋膜段；
- 传导过程中兴奋膜段数量只增加、不减少；
- 传导终点七个膜段全部兴奋，且播放停止。

### 组件与交互测试

- 三个模式使用同一个共享神经纤维节点；
- 每个 Na⁺通道与膜段有稳定语义标识；
- 局部电流的膜内、膜外箭头方向正确；
- 暂停保持当前帧，重新播放复位；
- 产生和传导均在终点停止；
- 不出现曲线、电压值、复极化、恢复等禁用内容；
- 减少动态效果下静态关键帧与禁用控件正确。

### 浏览器验收

- 逐个点击三个模式并完整播放；
- 检查中央产生顺序和三轮传导接力；
- 桌面端与 390px 移动端无裁切、重叠或横向滚动；
- 所有主要按钮达到至少 44px 点击高度；
- 浏览器控制台无错误。

## 9. 完成标准

用户无需借助膜电位曲线，就能从动画中回答：

1. 静息状态主要显示哪种离子运动？
2. 刺激后哪个通道先在局部开放？
3. Na⁺向哪个方向移动，局部膜电性如何改变？
4. 兴奋部位为什么能使相邻部位兴奋？
5. 离体神经纤维上的兴奋为什么能从刺激点向两侧传导？

当动画能够以同一根神经纤维、清晰的通道开闭、离子运动和局部电流逐段接力回答以上问题，并通过全部自动化与浏览器验收，即视为完成。
