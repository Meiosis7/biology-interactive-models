# 动作电位游离离子分布设计

## 目标

在静息电位、动作电位产生和动作电位传导三个模式中，始终直观呈现：

- 膜外 Na⁺多、K⁺少；
- 膜内 K⁺多、Na⁺少；
- 游离离子不遮挡正负号、离子通道、刺激标记、局部电流和动态进出通道的离子。

## 视觉方案

采用稀疏分布，并让游离离子围绕固定安全位置轻微、缓慢漂动。

- 上方膜外：6 个 Na⁺、2 个 K⁺；
- 下方膜外：6 个 Na⁺、2 个 K⁺；
- 膜内：8 个 K⁺、2 个 Na⁺；
- 三个模式复用同一组固定基准位置和运动参数，切换模式时节点不重建、不跳位；
- 游离离子尺寸和颜色对比低于进出通道的动态离子，以保证动画层级清楚；
- 游离离子水平位置落在相邻通道轴线之间，垂直位置避开四层正负号和局部电流弧线。

## 组件结构

新增 `IonDistribution` 展示组件，由 `ActionPotentialScene` 在膜纤维舞台中渲染一次。

- 组件内部维护确定性的离子位置表；
- 每个离子同时获得确定性的漂动轨迹、时长和延迟，避免整齐同步；
- 每个游离离子带有种类、区域和位置数据属性，便于自动验收；
- 单个离子对辅助技术隐藏，分布层提供简洁说明，避免逐个播报造成噪声；
- 分布层不读取动画进度，也不改变现有模拟状态。

## 动画和数据流

游离离子层是独立的教学背景，使用 CSS 小范围循环漂动，不参与动作电位帧计算：

1. `ActionPotentialLab` 继续产生现有帧数据；
2. `ActionPotentialScene` 渲染帧、通道、正负号和局部电流；
3. `IonDistribution` 始终按同一位置表渲染浓度差，并为每个离子提供确定性的运动参数；
4. 动态 Na⁺和 K⁺流仍沿通道孔运动，视觉层级高于背景游离离子。

## 自由漂动规则

- 每个离子采用不同方向、不同相位的缓慢闭合轨迹，单次循环为 7–11 秒；
- 桌面端相对基准位置的最大位移不超过 3px，手机端不超过 2px；
- 动画只改变 `transform`，不改变基准 `left`、`top`、节点顺序或离子数量；
- 静息和动作电位产生模式中，漂动跟随“播放/暂停”状态：暂停时冻结，继续时从冻结位置恢复；
- 动作电位传导模式没有暂停按钮，等待“下一步”时仍持续轻微漂动；
- `prefers-reduced-motion: reduce` 下取消漂动，离子保持在安全基准位置；
- 漂动幅度必须落在已验证的安全余量内，不能进入正负号、通道、刺激、动态离子或局部电流区域。

## 响应式布局

- 桌面端保留全部 26 个游离离子；
- 手机端保留相同数量，但缩小圆点和字号，并收紧纵向偏移；
- 手机端漂动幅度缩小到最多 2px；
- 所有离子必须位于场景边界内，页面不得产生横向滚动；
- “下一步”按钮位置和现有手机端紧凑布局不得改变。

## 验收标准

- 三个模式均显示膜外 Na⁺多、K⁺少和膜内 K⁺多、Na⁺少；
- 上下膜外各为 6 Na⁺/2 K⁺，膜内为 8 K⁺/2 Na⁺；
- 模式切换后分布节点与位置保持稳定；
- 游离离子缓慢、不同步地轻微漂动；
- 暂停、继续、传导等待和减弱动态模式符合上述自由漂动规则；
- 在完整漂动周期的多个采样点，游离离子不与正负号、通道、动态离子、刺激或局部电流重叠；
- 390×844 手机视口无横向溢出，下一步按钮仍在首屏可见；
- 减弱动态模式下分布保持静态可见；
- 现有产生循环、手动逐步传导和通道对齐逻辑不变。

## 测试策略

- 组件测试验证三层离子数量、种类、区域和稳定渲染；
- 场景测试验证三个模式都包含同一分布层；
- CSS 合同测试验证背景层层级、7–11 秒时长、桌面/手机位移上限、播放状态和减弱动态规则；
- 完成后运行动作电位聚焦测试、全量测试、代码检查和构建；
- 使用内置浏览器在 1280×720 与 390×844 下跨多个动画采样点检查真实边界、遮挡、暂停/继续和按钮位置。
