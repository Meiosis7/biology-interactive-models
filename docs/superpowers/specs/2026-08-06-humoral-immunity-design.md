# 体液免疫：动态交互模型设计

## 1. 学习目标

学生完成模型后应能：

1. 按顺序描述抗原呈递、辅助性 T 细胞活化、B 细胞活化、增殖分化、抗体产生和记忆细胞形成。
2. 说明抗原与抗体结合具有特异性。
3. 区分浆细胞与记忆 B 细胞的功能。
4. 比较初次免疫与二次免疫反应的速度和强度。
5. 判断抗原呈递、辅助性 T 细胞或 B 细胞环节受阻对抗体产生的影响。

## 3. 正常流程

1. 抗原进入并被抗原呈递细胞摄取、处理和呈递。
2. 与该抗原信息匹配的辅助性 T 细胞被激活。
3. 相应 B 细胞识别抗原，并获得辅助性 T 细胞提供的激活信号。
4. B 细胞进行克隆增殖。
5. 部分细胞分化为浆细胞，产生并分泌特异性抗体。
6. 抗体与相应抗原结合，形成沉淀或细胞集团等，随后被进一步清除。
7. 部分细胞形成记忆 B 细胞。

模型使用教材化因果链，不展开细胞因子名称、抗体类别转换和亲和力成熟机制。

## 4. 交互设置

- 抗原类型：A、B，两者用不同形状而非只用颜色区分。
- 暴露次数：初次、二次。
- 实验条件：正常、抗原呈递受阻、辅助性 T 细胞功能受阻、匹配 B 细胞缺失。
- 播放、暂停、单步、教学时间轴、慢速/正常、重置。

## 5. 初次与二次反应

- 初次反应具有较长潜伏期，抗体相对量上升较慢，峰值较低，并形成记忆细胞。
- 同种抗原再次进入时，记忆细胞迅速响应，抗体产生更快、相对量更高。
- 更换为另一种抗原时，不调用原抗原形成的记忆优势。
- 曲线仅表示相对变化趋势，不提供临床或定量免疫结论。

## 6. 防误解设计

- 抗体由浆细胞产生，不写成 B 细胞所有阶段都直接大量分泌。
- 辅助性 T 细胞提供激活信号，不直接产生抗体。
- 抗体不会直接“吞噬”抗原；动画显示特异性结合后由其他机制进一步清除。
- 记忆细胞不是持续大量分泌抗体的浆细胞。

## 7. 验收标准

- 正常流程顺序正确，分化分支清楚。
- A 抗体只与 A 抗原匹配，B 抗体只与 B 抗原匹配。
- 同种二次反应曲线更快、更高；异种抗原不享受该记忆优势。
- 三种受阻条件在相应环节影响后续抗体产生。
- 暂停后细胞移动、增殖和抗体释放动画停止。
