# 动作电位手机端紧凑控制设计

## 目标

解决手机打开动作电位模型后页面过长、每次点击“下一步”都需要滑到知识卡下方的问题。手机端应先完成观察与操作，再按需阅读知识说明。

## 手机端内容顺序

当视口宽度不超过 720px 时，页面按以下顺序显示：

1. 标题与三种模式
2. 动作电位动画图
3. 当前模式的操作按钮
4. 知识说明卡片

桌面端继续保持“动画图与知识卡左右并列、操作按钮位于其下方”的现有布局。

## 控制栏

- 传导模式保留“下一步”和“重新演示”。
- “下一步”为主要按钮，占据更多横向空间；“重新演示”为次要按钮。
- 两个按钮在常见手机宽度下一行排列，按钮高度不低于 44px。
- 控制栏放在动画图正下方，不使用悬浮或固定定位，避免遮挡正负号、通道、离子和局部电流。
- 产生、静息模式的“播放／暂停”和“重新播放”采用同一位置与尺寸规则。

## 紧凑布局

- 缩小手机端标题区的上下留白、工作区间距、卡片内边距和控制栏外边距。
- 保持三模式按钮清楚可点，单个按钮触控高度不低于 44px。
- 保持动画内的神经纤维、四层正负号、上下通道、离子动画和局部电流现有尺寸与教学关系，不通过整体缩小动画来压缩页面。
- 知识卡置于控制栏之后，可继续向下滚动查看，但不再阻碍连续操作。

## 实现边界

- 只调整 `ActionPotentialLab` 的布局容器和动作电位样式。
- 不修改模拟状态、传导步骤、播放节奏、文案和其他五个模型。
- 使用同一组控制组件，避免桌面端和手机端各渲染一份而造成重复按钮或状态不同步。

## 验收标准

- 390×844 手机视口中，动画底部之后立即出现控制栏，知识卡在控制栏之后。
- 传导模式中点击“下一步”后，下一步按钮仍在当前位置附近，无需滚动至知识卡底部。
- 两个控制按钮可见宽度合理、高度均不低于 44px，无横向溢出。
- 桌面端布局与当前版本一致。
- 三种模式切换、播放／暂停、下一步、重新演示和减弱动态模式均保持正常。
