# 动作电位通道对齐与手动传导设计

## 目标

在现有三个模式和同一根七段开放式神经纤维基础上，解决两个教学问题：

1. Na⁺必须从可见通道孔中心进出，通道与离子路径不能错位。
2. 动作电位传导改为手动点击“下一步”推进，清楚展示“动作电位形成 → 局部电流形成 → 相邻动作电位形成 → 新局部电流形成”的因果关系。

本轮不增加膜内外游离 Na⁺、K⁺背景粒子。

## 保留内容

- 仍只有三个模式：静息电位、动作电位产生、动作电位传导。
- 静息模式的上下膜 K⁺外流保持自动循环。
- 动作电位产生模式保持自动循环，仍依次显示刺激、Na⁺通道开放、Na⁺内流、中央膜段兴奋。
- 每段四个稳定电荷槽；静息为 `＋,−,−,＋`，兴奋为 `−,＋,＋,−`。
- 上下膜通道保持左右开启，不增加曲线、mV、复极化、超极化或恢复过程。
- 神经纤维两端保持开放。

## 通道与离子路径

每个膜段使用两条固定竖直视觉通道：

- 电荷列位于膜段宽度 25%。
- Na⁺通道、通道孔与 Na⁺粒子流位于膜段宽度 75%。

上下膜 Na⁺通道使用相同的水平坐标。上膜 Na⁺竖直向下穿过上膜通道孔进入膜内，下膜 Na⁺竖直向上穿过下膜通道孔进入膜内。删除现有 Na⁺横向绕行关键帧和 `--ion-bypass-x`；粒子的横向中心在整个动画中始终等于对应通道孔中心。

移动端可缩小通道和粒子，但不得改变电荷列与通道列的相对位置。两列、相邻膜段元素、标签和开放端在 390×844 与 1280×720 下均不得相交或溢出。

## 手动传导状态机

传导模式不再由统一 6 秒时间轴自动连续播放。进入传导模式时显示第 0 步，并停住等待操作：

0. 中央第 4 膜段已经形成动作电位。
1. 点击“下一步”：第 1 轮局部电流从箭尾向箭头逐渐形成，完成后保持。
2. 点击“下一步”：第 3、5 膜段的上下 Na⁺通道开放，Na⁺从通道孔进入；四个电荷一起翻转，三个中央膜段形成动作电位，随后停住。
3. 点击“下一步”：第 2 轮局部电流逐渐形成，完成后保持。
4. 点击“下一步”：第 2、6 膜段形成动作电位，随后停住。
5. 点击“下一步”：第 3 轮局部电流逐渐形成，完成后保持。
6. 点击“下一步”：第 1、7 膜段形成动作电位，七段全部兴奋，随后进入总结终态。

每次点击只推进一个宏观教学步骤。局部电流和动作电位形成步骤内部可自动播放一次短动画；播放期间“下一步”暂时禁用，动画完成后重新启用。不得自动进入下一个宏观步骤。

传导模式的主控制为“下一步”和“重新演示”。“重新演示”回到第 0 步。最终步骤禁用“下一步”，但保留“重新演示”。静息和产生模式继续使用现有播放/暂停与重新播放控件。

## 局部电流动画

每个局部电流步骤仍只有四条短弧：

- 膜内两条：由当前兴奋区分别指向左右未兴奋区。
- 膜外两条：由左右未兴奋区分别返回当前兴奋区。

SVG path 使用确定的尾端到首端方向。每条弧线在 520 ms 内以 `stroke-dashoffset` 从 1 变为 0，从箭尾向箭头逐渐绘制；四条弧按 DOM 顺序分别延迟 0、60、120、180 ms。箭头在对应路径绘制完成时出现。最后一条弧在 700 ms 完成。绘制完成后弧线保持完整，不循环闪动，直到下一次点击使相邻膜段形成动作电位后消失。

## 动作电位形成步骤

每一轮相邻动作电位形成使用 1400 ms 的内部时间线：

1. 0—300 ms：目标膜段仍保持 `＋,−,−,＋`，上下 Na⁺通道左右开放。
2. 300—1150 ms：上、下 Na⁺各三粒从对应通道孔中心进入膜内；单粒持续 650 ms，并以 100 ms 错峰，因此最后一粒在 1150 ms 前完成。
3. 1150 ms：目标膜段四个电荷同时翻转为 `−,＋,＋,−`。
4. 1150—1400 ms：粒子消失，画面稳定为新增膜段已经兴奋的状态；1400 ms 时重新启用“下一步”。

不得在 Na⁺内流尚未完成时提前翻转任何一个电荷。

## 总结终态

七段全部兴奋后，不保留瞬时局部电流短弧，避免暗示整条神经纤维同时存在局部电位差。画面显示从中央指向左右的总结性双向箭头，并显示结论：

> 神经冲动以电信号（局部电流）的形式在神经纤维上双向传导。

总结箭头表示整体传导方向，不表示终态仍存在连续的局部电流。

## 减少动态效果与可访问性

- `prefers-reduced-motion: reduce` 下不运行 RAF 或 CSS运动动画；每次点击“下一步”直接显示该宏观步骤的完成静态帧。
- “下一步”使用明确的按钮名称，并通过说明文本报告当前第几步、正在形成什么以及下一步将发生什么。
- 自动播放短动画期间不重复播报每一帧；动画停住后再以礼貌方式播报新的教学状态。
- 保留通道、离子流、局部电流内外方向和上下膜面的可访问名称。

## 验收标准

- Na⁺粒子横向中心始终与对应 Na⁺通道孔中心对齐，桌面和手机端实际边界测量偏差不超过 1 px。
- 产生模式仍自动循环，且离子严格穿孔。
- 传导模式只有用户点击“下一步”才进入下一个宏观步骤。
- 三轮顺序严格为：中央动作电位 → 局部电流 1 → 相邻动作电位 1 → 局部电流 2 → 相邻动作电位 2 → 局部电流 3 → 相邻动作电位 3 / 总结。
- 每个局部电流步骤恰有四条弧，均从尾端向首端逐渐绘制后保持。
- 每个动作电位形成步骤都先开放通道和 Na⁺内流，再原子翻转电荷并停住。
- 最终结论文字逐字正确，且总结性双向箭头与瞬时局部电流弧在语义和样式上可区分。
- 暂停/重播、模式切换、减少动态效果、开放端、七段稳定 DOM 和禁止内容均无回归。
- 1280×720 与 390×844 下无横向滚动，所有通道、粒子、电荷、弧线、标签和控制按钮均可见且互不遮挡。
