# 膜电位模型持续离子运动设计

## 目标

让膜两侧的 Na⁺、K⁺ 始终保持可见的轻微无规则运动；当某类离子通道开放时，让对应离子持续沿明确方向穿膜。暂停时间轴时，只暂停膜电位阶段推进，不冻结微观粒子运动。

## 交互表现

- 膜外 Na⁺ 和膜内 K⁺ 使用多组不同轨迹、周期与负延迟，形成不同步的小幅漂移。
- 粒子分布在区室内不同高度，不再整齐排列成一条直线。
- 游动范围扩大到约 10–16 px，并配合 2.8–4.1 秒的不同周期，使运动在普通浏览器视口中一眼可见。
- 粒子素材层进行轻微呼吸式缩放和亮度变化，增强运动感但不影响 Na⁺、K⁺ 文字识别。
- Na⁺ 通道开放时，Na⁺ 流动粒子持续由膜外向膜内运动。
- K⁺ 通道开放时，K⁺ 流动粒子持续由膜内向膜外运动。
- 穿膜动画不依赖时间轴的播放状态；当前阶段有离子流时，即使暂停也继续展示离子迁移方向。
- 保留系统“减少动态效果”设置下的降级规则。

## 验收标准

1. 静止于任意时间点时，区室内粒子仍持续漂移。
2. 静止于 Na⁺ 内流或 K⁺ 外流阶段时，穿膜粒子仍持续移动。
3. 播放和暂停不改变离子微观动画，只改变时间轴是否自动推进。
4. 多个粒子的高度、周期和延迟不同，不出现整齐同步摆动。
5. 现有膜电位曲线、通道开闭、高亮、速度与重置交互不受影响。
