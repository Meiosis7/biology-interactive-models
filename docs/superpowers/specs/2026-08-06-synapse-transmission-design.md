# 兴奋在突触处的传递：动态交互模型设计

## 1. 学习目标

学生完成模型后应能：

1. 按顺序描述兴奋在化学突触处传递的主要过程。
2. 将动作电位到达、Ca²⁺内流、突触小泡融合、神经递质释放、受体结合和突触后膜变化正确对应。
3. 理解兴奋在化学突触处具有单向传递和突触延搁。
4. 区分兴奋性递质与抑制性递质对突触后膜的不同影响。
5. 判断阻断 Ca²⁺通道、阻断受体或抑制递质清除对传递结果的影响。

## 2. 页面结构

主画面为纵向放大的突触结构：上方突触前膜、突触小泡与 Ca²⁺通道；中部突触间隙；下方突触后膜与受体。右侧为阶段解释卡，下方为突触后膜电位曲线和统一控制区。

主视图必须显示：动作电位到达的传播光带、Ca²⁺跨膜进入、突触小泡向前膜移动并融合、递质释放与扩散、受体结合、离子通道响应和递质清除。所有粒子为教学示意。

## 3. 交互设置

- 突触类型：兴奋性、抑制性。
- 实验条件：正常、Ca²⁺通道阻断、突触后受体阻断、递质清除受抑制。
- 播放、暂停、单步、教学时间轴、慢速/正常、重置。

改变突触类型或实验条件后自动回到初始状态。

## 4. 正常时间线

1. 静息：小泡位于突触前末梢，递质未释放。
2. 动作电位到达：突触前膜发生去极化。
3. Ca²⁺通道开放：Ca²⁺进入突触前末梢。
4. 小泡融合：部分突触小泡与突触前膜融合。
5. 递质释放：神经递质进入突触间隙并扩散。
6. 受体结合：递质与突触后膜特异性受体结合。
7. 突触后效应：兴奋性模式使膜电位升高；抑制性模式使膜电位降低或更难达到阈值。
8. 递质清除：递质被分解、回收或扩散离开，突触恢复准备状态。

## 5. 条件分支

- Ca²⁺通道阻断：动作电位可到达，但 Ca²⁺内流和小泡有效释放显著受阻，突触后膜无明显响应。
- 受体阻断：递质可正常释放，但不能有效引起突触后膜响应。
- 清除受抑制：突触后效应持续时间延长，曲线恢复变慢；不解释为单个动作电位幅度无限增大。

## 6. 防误解设计

- 明确神经递质跨越的是突触间隙，不是沿突触后神经元长距离传播。
- 明确单向传递来自递质释放装置主要位于突触前膜、受体主要位于突触后膜。
- 明确突触延搁来自释放、扩散和受体响应等环节。
- 兴奋性/抑制性描述为突触后膜效应，不将某一种递质绝对固定为所有突触中的单一作用。

## 7. 验收标准

- 正常模式的七个关键事件顺序正确且同步。
- 兴奋性与抑制性曲线方向不同，解释文字一致。
- 三种阻断/干预条件在正确环节停止或改变后续过程。
- 暂停时递质、Ca²⁺和小泡动画停止。
- 反向刺激突触后侧不会触发完整逆向化学传递，并显示单向传递提示。
