# 高中生物动态交互模型套件：统一架构设计

## 1. 范围

在现有“动作电位的形成和传导”模型基础上，新增五个独立模型：

1. 兴奋在突触处的传递。
2. 膜电位变化曲线。
3. 电表指针偏转问题。
4. 体液免疫。
5. 细胞免疫。

每个模型拥有独立文件夹、独立页面、独立状态逻辑、独立样式入口和独立测试。六个模型由统一主页进入，但任一模型均可通过自己的地址单独打开。

## 2. 推荐目录

```text
models/

  03-membrane-potential-curve/
  04-meter-deflection/
  05-humoral-immunity/
  06-cellular-immunity/

  synapse-transmission/
```

每个 `models/<name>/` 文件夹至少包含：页面级实验组件、纯状态或模拟逻辑、分区视图组件、局部样式和类型。跨模型只共享无业务含义的基础组件，如模型导航、统一按钮和阶段时间轴；不共享具体生理或免疫流程逻辑。

## 3. 统一体验

- 深蓝色实验台背景，青色表示激活/输入，紫色表示调控或另一类离子，暖黄色表示当前关键步骤，红橙色表示电位、强度或结果曲线。
- 页面顶部显示主题、学习任务和高中生物范围声明。
- 主视图展示动态过程；辅助视图展示曲线、指针或数量变化；右侧解释卡说明“当前事件、发生位置、原因、结果”。
- 控制区统一提供播放、暂停、上一步、下一步、教学时间轴、慢速/正常和重置。
- 所有时间与数量均标明为教学示意，不代表真实生理比例或真实秒尺度。
- 关键状态同时使用颜色、形状、位置和文字表达。
- 每个页面支持键盘操作、平板横屏和 760 px 以下单列布局，并尊重 `prefers-reduced-motion`。

## 4. 模型主页

根页面升级为模型主页，展示六张主题卡片。每张卡片包含：主题编号、名称、核心学习任务、状态标签和“进入模型”链接。第一个动作电位模型保留原有内容并迁移到 `/models/action-potential`；根页面不再直接承载单个模型。

导航允许在模型页返回主页或切换前后模型。模型之间不自动共享实验状态，避免学生误把一个模型的设置带入另一个模型。

## 5. 状态与动画原则

- 每个模型使用纯函数或明确状态机派生当前步骤，不使用散落的独立动画计时。
- 播放、单步、拖动时间轴均读取同一状态源，保证主视图、辅助视图和解释卡同步。
- 改变会影响实验结论的设置时，模型停止播放并回到初始状态。
- 暂停后所有粒子、箭头、指针和流程动效停止，页面仍能静态理解。
- 连续动画不得表达教材没有支持的连续定量关系。

## 6. 教学边界

- 使用高中选择性必修 1 的常用术语和因果链。
- 不引入大学层级的通道动力学、受体亚型、细胞因子网络或免疫分子定量方程。
- 对教材中的示意过程使用“主要”“促进”“形成”等表述，避免把简化动画写成唯一真实机制。
- 对常见易错点设置显式提示，而不是只通过动画暗示。

## 7. 验证策略

每个模型至少包含：

- 纯逻辑测试：阶段、条件分支、顺序和边界。
- 真实组件交互测试：设置变更、时间轴、暂停、单步和重置。
- 同步测试：主视图、辅助视图和解释卡读取同一状态。
- 可访问性测试：标签、按钮状态、键盘可操作控件和动态区域。
- 页面与路由测试：每个模型可独立访问，主页链接正确。

全套完成后运行全部测试、代码检查和生产构建。
